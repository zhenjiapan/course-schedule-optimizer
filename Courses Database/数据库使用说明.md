## Python 调用

将数据库和 `query_courses.py` 放在同一目录，运行：

```bash
python3 query_courses.py
```

在自己的程序中调用：

```python
from query_courses import get_course, get_schedule, find_by_weekday

course = get_course('MAT1001')
sections = get_schedule('MAT1001')
monday = find_by_weekday(1)
```

也可以直接用标准库：

```python
import sqlite3

with sqlite3.connect('term1_2026_2027.sqlite') as conn:
    rows = conn.execute(
        'SELECT section_code, days_raw, start_time, end_time, room '
        'FROM schedule WHERE course_code = ?', ('AIE1001',)
    ).fetchall()
```

如已安装 pandas，可使用 `pd.read_sql_query('SELECT * FROM schedule', conn)` 进行分析。

## 表和视图

- `courses`：课程代码、名称、学历、学分、评分基准、校园、培养单位、学术组织、注册要求、完整描述。
- `course_components`：讲演、指导教学等组件及必需标记。
- `course_attributes`：授课语言等页面课程属性。
- `sections`：课程、学期、区段、组件缩写、班级编号及期次。
- `meetings`：区段的每条上课时段；关联区段的 `section_id`，并保留原始星期、时间、日期、讲师文本。
- `meeting_days`：每条时段的星期，1=星期一，7=星期日。
- `instructors` / `meeting_instructors`：讲师及每条时段的讲师关联，可表示多名讲师。
- `sources`：采集时间、来源、原始课程字段文本、网页归档校验值与页面区段总数。
- `schedule`（视图）：便于查询的课程、区段与时段汇总。
- `course_summary`（视图）：课程及区段数量汇总。

`start_time` / `end_time` 使用24小时 `HH:MM`；日期使用 `YYYY-MM-DD`，时区按学校所在地 Asia/Shanghai。原始值保存在 `_raw` 字段中。若 SIS 只显示 TBA，标准化时间或日期为 NULL，原始值仍保存。未显示的可选课程字段为 NULL，绝不据此补写要求。

此库包含已入库课程的全部可选区段，未标记个人实际选课。“员工”保留原文，并在讲师表以 `is_placeholder=1` 标记，表示页面没有提供具体姓名。

本次范围与此前确认的截图一致：课程详情和区段时段列表；未额外提取 `View Course Outline` 文件或点击每个班级后的扩展详情。课程安排是采集时点快照。
