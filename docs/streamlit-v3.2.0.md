# v3.2.0 使用与维护

## 排课流程

1. 选择 2026–27 第一或第二学期，添加课程，展开班次表查看组件、配对、教学时间、教室和教师。
2. 学分上下限默认 12 和 18，均可修改。这是求解输入，学校实际选课上限以 SIS 为准。早八指 08:30 开始的课程。
3. 必选、锁定、排除、全天禁排、自定义禁排和禁止早八属于硬约束。自定义禁排每行输入 `星期数字,开始,结束`，例如 `1,08:30,12:00`；结束时间早于开始时间表示跨午夜。
4. 教师、星期、时段和早八偏好采用 1–5 档，3 为中性。最早上课和最晚下课可设为硬约束或偏好。可设置课间空档、分时段的节数、周内分布、空闲工作日和各类评分权重。启用周内规则时，选择参与评估的教学周。
5. 搜索采用 CP-SAT。运行中每秒刷新进度，约每十秒刷新前三个候选。前三名完成证明后，求解器继续枚举合格组合。合格课表总数包含前三名之外的可行组合，分支总数是求解器用于搜索的分支统计。
6. 查看某个教学周或切换推荐方案。可调整同一组件内的班次，系统会重新独立校验。通过校验后可导出 CSV 或 JSON。

## 数据与版本

- v3.2.0 使用只读 SQLite。默认文件是 `streamlit-v3.2.0/private/sis-2026-11-24-fin2010.sqlite`。快照按学期统计为第一学期 493 门、1476 个班次，第二学期 13 门、256 个班次。
- FIN2010 第二学期有 24 个班次和 44 条配对记录。以最低学分设为 0 的单课请求验证了 44 个合格组合和 3 个推荐方案。
- 班次和资格以学校 SIS 为准。快照是本地数据，另行部署时须提供可使用的快照。若提示缺少文件，检查默认路径或 `COURSE_SNAPSHOT`。
- v3.1.0 采用 Next.js、FastAPI 和 PostgreSQL，其启动及部署说明随归档保留。v3.2.0 在本机直接使用 Streamlit。
- 若 8501 已占用，可改用 `--server.port 8502` 并打开相应端口。
